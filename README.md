## 第一笔账：澳元结算，折算值不等于你付的钱

WePC 默认按澳元计费，支持支付宝、微信、信用卡和 PayPal。用支付宝或微信时，系统按实时汇率折算成人民币，你看到的"约 52 元"是照 1:4.8 估算出来的，实际扣款会随汇率浮动几毛到一两块。

用 PayPal 的话，注册账户时要把币种选成澳币。选人民币账户结算，PayPal 会先做一次货币转换，多一层汇损，长期月付下来不划算。

再提醒一句：本文所有人民币数字都是按 1 澳元≈4.8 元估算的原价或折后价，没有再叠加任何支付通道手续费，也没有考虑银行侧的货币转换费。结账页显示多少就是多少。

## 第二笔账：流量双向计算，超了限速不停机

官网每个套餐都写"X TB 双向流量"，意思是上传加下载合计。1.5TB 的套餐，传 800GB 素材、拉 700GB 回来，额度就用完了。

额度用完之后不是停机，是限速。官方政策是限到 5Mbps 或 10Mbps，不额外收费、不中断服务。对发短视频来说，限速只是慢；对直播来说，中途被限到 5Mbps 基本等于推流断掉。做直播的话，要么选流量档位高一档的套餐，要么在后台盯紧用量，别在开播前把额度跑光。

## 按目标市场选节点，别只看价格

TikTok 是区域化分发的平台，账号登录 IP 的地区要和你想做的市场对上。按市场给几条决策规则：

**做美区**：洛杉矶 4837 静态家宽（12.90，无需中转）或 9929 家宽直播（16.90）。9929 走的是三网优质回程，直播推流更稳；只发短视频、不起直播，4837 够了，省 4 澳元。

**做日韩**：东京和首尔都是 19.90，2核 512MB、2TB 双向流量，配置比欧美入门档高一档。日本页面写着"无优化，需要中转"，韩国是电信移动直连、联通绕路，选之前先确认自己的宽带运营商。

**做东南亚**：新加坡 16.90 是原生 IDC IP，不是家宽，电信必须中转；印尼 19.90 是原生家宽，但带宽只有 50Mbps，联通电信需中转。这两个节点更适合作为矩阵里的补充，不适合当主力。

**做欧洲**：德国 10.90 最便宜，电信要中转；英国 10.90 是非家宽 IP；法国 14.90、西班牙 19.90 都是家宽但要中转。欧洲整体是"价格低、直连差"的组合。

**做中东**：阿联酋 24.90，是全场第二贵，带宽 100Mbps、2TB 双向，页面标注建议中转。除非目标市场就是海湾地区，否则性价比不高。

延迟方面，有第三方评测记录到：香港、日本、韩国节点国内访问约 40–80ms；美国洛杉矶 AS9929 约 150ms；澳大利亚机房移动、联通 80–120ms，电信会绕美国、延迟更高。这些是测评作者的自测数据，不是官方 SLA，你的实际延迟取决于本地运营商和时段。
